# ADR-015: 회원 탈퇴와 재인증·카카오 연결 끊기

- 상태: 승인됨 (연결 끊기가 계속 실패하는 계정의 처리는 결정 대기, 아래 "열린 문제")
- 날짜: 2026-10-17

## 맥락
- PRD AUTH-5: 회원 탈퇴 시 즉시 로그인 차단, 개인정보는 30일 뒤 파기.
- 카카오 공식 문서: 서비스 탈퇴 시 카카오 연결 끊기(unlink)를 **반드시** 호출해야 한다. 회원번호(user_id)도 지워야 할 개인정보다.
- 우리는 카카오 액세스 토큰을 보관하지 않는다(ADR-014). 탈퇴 시점에도, 실패 후 다시 시도할 때도 토큰 없이 끊을 수 있어야 한다.
- M1-c 결정 1(B안): 유예 중에도 같은 이메일·카카오 계정으로 새로 가입할 수 있고, 탈퇴 복구는 지원하지 않는다(V9).

## 결정
1. **상태 전이**: `Landlord.withdraw(now)`로만 `ACTIVE → WITHDRAWN`, `withdrawn_at` 기록. 되돌리는 전이는 없다. 이미 탈퇴한 계정을 다시 탈퇴하면 예외.
2. **재인증**(민감 작업)
   - 이메일 가입 계정: 지금 비밀번호 + 확인 체크. 틀리면 로그인 실패 횟수에 더한다(ADR-012). 잠기면 15분 대기.
   - 카카오 계정(M1-c 결정 2·12): 확인 체크를 POST로 받으면 세션에 "탈퇴 의사 확인"(`KakaoWithdrawalIntent`: landlord id + 만료 10분)을 저장하고, 카카오 재로그인 **링크(GET)** 를 보여 준다(CSP form-action 때문에 카카오 주소로 폼을 보낼 수 없다, ADR-014). 이 세션의 인가 요청에는 `prompt=login`을 붙여 카카오에 로그인돼 있어도 다시 입력하게 한다.
   - 카카오 콜백에서 의사 확인을 꺼내(한 번만 사용):
     - 같은 계정 + 10분 안 → 바로 탈퇴, 로그아웃, `/withdrawn`
     - 같은 계정 + 10분 지남 → 탈퇴하지 않고 탈퇴 화면(`?expired`)
     - 다른 카카오 계정 → 탈퇴하지 않는다. 로그인 상태가 그 계정으로 바뀌었으므로 로그아웃시키고 `/login?withdrawMismatch`
     - 카카오에서 취소·실패 → 탈퇴 화면(`?kakaoError`), 원래 로그인은 그대로
   - 의사 확인이 없는 보통 카카오 로그인에는 `prompt`를 붙이지 않고 탈퇴도 하지 않는다.
   - 카카오톡 인앱 브라우저는 `prompt=login`을 지원하지 않는다(카카오 문서). User-Agent에 `KAKAOTALK`이 있으면 "다른 브라우저로 열기" 안내를 보여 준다.
3. **즉시 차단**(한 트랜잭션): 탈퇴 상태로 변경 → 모든 기기의 세션과 remember-me 토큰 삭제(`AccountSessionTerminator`) → 메일 링크(account_token)·로그인 실패 기록 삭제 → 지금 기기 로그아웃(세션 무효화, remember-me 쿠키 삭제). 이메일·카카오 로그인과 remember-me 조회는 ACTIVE만 찾으므로 바로 로그인할 수 없다.
4. **안내 메일**: 인증된 이메일이 있을 때만, 커밋 뒤에 보낸다(M1-b 결정: 알림은 인증된 주소로만).
5. **카카오 연결 끊기**: 서비스 앱 어드민 키 방식(`POST /v1/user/unlink`, `Authorization: KakaoAK {어드민 키}`, `target_id_type=user_id`, `target_id={회원번호}`).
   - 탈퇴 트랜잭션이 **커밋된 뒤** 호출한다. 카카오 응답을 기다리는 동안 DB 연결을 잡지 않고, 카카오가 실패해도 탈퇴를 되돌리지 않는다.
   - 성공하면 `landlord.kakao_unlinked_at`(V10)에 시각을 남긴다. 실패하면 NULL로 남고 파기 배치가 다시 시도한다. 기록은 새 트랜잭션으로 한다(커밋 직후 콜백에서 기존 트랜잭션에 참여하면 커밋되지 않는다).
   - 어드민 키와 회원번호는 로그에 남기지 않는다(landlord id와 예외 종류만).
6. **V10 제약** `ck_landlord_kakao_unlinked`: `kakao_unlinked_at`은 탈퇴한 카카오 계정에만 있을 수 있다. 이메일(LOCAL) 계정과 사용 중인 계정은 항상 NULL.
7. 카카오 계정은 비밀번호가 없으므로 비밀번호 탈퇴 요청은 404, 이메일 계정의 카카오 탈퇴 요청도 404.

## 검토한 대안
| 대안 | 채택하지 않은 이유 |
|---|---|
| 카카오 계정도 확인 체크만으로 탈퇴 | 세션을 가로챈 사람이 바로 탈퇴시킬 수 있다(결정 2) |
| 액세스 토큰으로 연결 끊기 | 토큰을 보관해야 한다(ADR-014와 충돌). 실패 후 다시 시도할 수 없다 |
| 연결 끊기 성공 여부를 기록하지 않고 파기 때마다 다시 호출 | 이미 끊긴 회원을 다시 끊을 때의 카카오 응답을 확인하지 못했다. 잘못 판단하면 계정이 영원히 파기되지 않는다 |
| 탈퇴 트랜잭션 안에서 연결 끊기 | 외부 호출 동안 DB 연결을 잡고, 카카오 장애가 탈퇴 자체를 막는다 |

## 열린 문제 (결정 대기)
- 카카오 장애·어드민 키 오류로 연결 끊기가 **계속 실패하는 계정**을 파기 배치가 어떻게 다룰지(실패 횟수 기록, 재시도 한도, 한도 뒤 처리, 운영자 알림). 결정 뒤 이 ADR에 추가한다.
- 연결 끊기는 성공했지만 `kakao_unlinked_at` 기록이 실패한 경우(DB 오류) 파기 배치가 다시 호출한다. 이미 끊긴 회원에 대한 카카오 응답은 확인하지 못했으므로 위 결정에 함께 포함한다.

## 결과
- 탈퇴하면 그 순간부터 어떤 기기·방법으로도 로그인할 수 없고, 같은 이메일·카카오 계정으로 새로 가입할 수 있다.
- 파기(30일 뒤 행 삭제)는 별도 배치가 맡는다(커밋 6).
