# ADR-029: 알림에 넣는 세입자 링크 (ADR-026 보완)

- 상태: 승인됨 (M5 커밋 3·4, M5 결정 7·8, 개발자 변경 1·3)
- 날짜: 2026-10-24

## 맥락
- 세입자 안내 문자에는 세입자 화면 링크가 들어가야 한다. 그런데 링크 원문은 저장하지 않는다(ADR-026: 해시만, 만든 화면에 한 번만 보임).
- M4는 계약당 열린 링크를 하나로 정했다(M4 결정 3). 알림을 보낼 때마다 링크를 새로 만들면 임대인이 직접 보낸 링크가 끊긴다.
- 임대인은 링크가 새어 나갔을 때 [링크 닫기]로 막을 수 있어야 한다. 알림이 다음 날 새 링크를 만들어 버리면 닫기의 뜻이 없어진다.

## 결정
- **C안: 알림 전용 링크 유형** (V20 `tenant_access_token.purpose`)
  - LANDLORD = 임대인이 계약 상세에서 직접 만든 링크, NOTIFICATION = 알림을 보낼 때 만든 링크. **계약·유형마다** 열린 링크는 하나다(`ux_tenant_access_token_open (lease_id, purpose) WHERE revoked_at IS NULL`). V17은 고치지 않고 V20에서 인덱스를 지우고 다시 만들었다.
  - 알림을 보낼 때마다 `TenantLinkService.issueForNotification`이 계약 행을 잠그고, 열린 알림 링크를 닫은 뒤(NOTIFICATION_ROTATED) 새로 만든다. 임대인 링크는 건드리지 않는다. 동시에 여러 번 불러도 열린 알림 링크는 하나다(테스트).
  - **알림을 실제로 보내는 시점에만** 만든다. 보내지 않는 알림(채널 꺼짐·수신 거부·알림 멈춤·상태 바뀜·하루 1통)에는 만들지 않는다(테스트). 원문은 본문에만 넣고 DB·로그·예외에 남기지 않는다.
  - 세입자 화면에서 두 유형은 똑같이 동작한다. 신고 이력의 actor_id도 그 링크 ID다.
- **닫은 이유** `revoke_reason`: LANDLORD_CLOSED / LANDLORD_REISSUED / NOTIFICATION_ROTATED / UNKNOWN. V20 전에 닫힌 행은 이유를 추정하지 않고 UNKNOWN으로 채웠다(개발자 변경 3). 앱은 UNKNOWN을 쓰지 않는다.
- **[링크 닫기]의 효력** (개발자 변경 1)
  - 두 유형을 모두 닫고(LANDLORD_CLOSED), 그 계약의 세입자 알림을 멈춘다(`lease.tenant_notify_paused_at`, V20).
  - 멈춘 동안 세입자 알림은 SKIPPED(LINK_CLOSED_BY_LANDLORD)이고 알림 링크도 만들지 않는다.
  - [새 링크 만들기]로는 풀리지 않는다. 임대인이 계약 상세의 **[알림 다시 켜기]**를 눌러야 다시 보낸다(다음 알림에 새 링크).
  - 닫기 확인 화면에 "세입자 안내 문자도 멈춰요. … 다시 보내려면 계약 화면에서 [알림 다시 켜기]를 눌러 주세요"를 적었다.
- **잘못된 링크 화면**: 예전 알림 링크·닫힌 링크·기간이 지난 링크·틀린 링크·없는 주소는 모두 같은 404 화면이다(M4 51번 규칙). 문구: "링크가 맞지 않거나 기간이 지났어요. 가장 최근에 받은 안내 문자의 링크를 열거나, 집주인에게 새 링크를 요청해 주세요."
- **수신 거부는 링크가 아니라 세입자에 저장한다**(V18, 개발자 변경 2): 알림 링크가 바뀌어도, 같은 세입자의 다른 계약에도 유지된다(테스트).

## 검토한 대안
| 안 | 내용 | 채택하지 않은 이유 |
|---|---|---|
| A | 보낼 때마다 새 링크, 계약당 하나 유지 | 임대인이 직접 보낸 링크까지 매번 끊긴다 |
| B | 보낼 때마다 새 링크, 예전 링크도 열어 둠 | 열린 링크가 문자 수만큼 늘고 각각 계약 끝 + 90일까지 유효하다. 새어 나갈 곳이 커진다 |
| D | 원문을 암호화해 저장하고 다시 쓰기 | "해시만 저장"(ADR-026)이 깨진다. DB와 키가 함께 새면 모든 링크를 빼앗긴다 |

## 결과
- 세입자가 오래된 안내 문자의 링크를 열면 열리지 않는다. 화면 문구로 가장 최근 문자를 열도록 안내한다.
- 열린 링크는 계약당 최대 두 개(임대인 링크 + 알림 링크)다.
- [새 링크 만들기]는 임대인 링크만 바꾸고 알림은 그대로 둔다. 알림 링크까지 끊고 싶으면 [링크 닫기]를 누르고, 알림을 다시 보내려면 [알림 다시 켜기]를 눌러야 한다(두 단계).
